# ChatbotComRegras
Entrega 02 da matéria Desenvolvimento de Chatbot da Uniderp - 8° semestre, Uniderp, do aluno Murilo de Souza Santos.

Este é um chatbot simples e interativo para terminal, desenvolvido em Java. Ele atua como um assistente virtual para a loja "Jogos, Games e Juegos", respondendo a perguntas frequentes de clientes e permitindo a reserva de títulos.

## Funcionalidades:
O bot analisa as mensagens do usuário em busca de palavras-chave para fornecer as seguintes informações:

  - Saudações;
  - Catálogo de Jogos;
  - Horário de Funcionamento;
  - Localização:
  - Preços;
  - Consoles/Videogames;
  - Reserva de Jogos;
  - Encerrar o chat.

## Pré-requisitos:
  Para compilar e rodar este projeto, você precisará ter o Java Development Kit (JDK) instalado em sua máquina.

## Como Executar:
  - Salvar o arquivo do chabot;
  - Executar o código;
  - Interagir: O programa começará a rodar diretamente no seu terminal. Basta digitar suas dúvidas e apertar Enter. Para fechar o assistente, digite "sair", "encerrar" ou "tchau".
